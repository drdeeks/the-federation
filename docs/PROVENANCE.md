# Federation Provenance and Disclosure Rules

This repository describes The Federation. It does not infer or invent authors,
contributors, collaborators, sponsors, model authorship, or AI authorship.

## Active integrations

- Federation Watchtower is an integration point for monitored tool/function
  events, immutable audit records, and related observability signals.
- CharacterKit is an integration point for agent character, habits, and
  behavioral configuration.
- Google ADK and Gemini are implementation components for the current
  application slice when they are present in the build.

These integrations do not define The Federation and must not be presented as
the parent product.

## Reusable local capabilities

`shared/memory` and `shared/enforcement` contain reusable capability work that
has been reorganized under the Federation workspace. Active code should use
Federation-neutral names and interfaces. Historical source labels, archive
paths, and unrelated project identities do not belong in runtime comments,
package names, or submission copy.

The repository may retain superseded material in `.trash/legacy/` for recovery,
but that directory is not active source and must not be imported.

## Submission safety

- Technical dependencies may be disclosed when they are factual and relevant.
- A technology dependency is not an authorship credit.
- No attribution, co-author, collaborator, sponsor, or ownership claim may be
  added unless the user explicitly supplies and approves it.
- Submission materials remain drafts until the user explicitly requests a
  submission or external update.

This document is a repository rule, not a claim about any individual or
organization.
